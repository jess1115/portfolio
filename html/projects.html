AI-Enhanced F1 Simulator

Project Lead & Core Developer · MSc Group Project · IBM UK Client

Overview

An AI-assisted driver coaching system built around the TORCS racing simulator. It collects real-time driving telemetry, provides a custom dashboard for monitoring performance, and uses local LLM inference to generate driver coaching feedback.


Developed as part of my MSc group project for an IBM UK client, the system combines TORCS, Python middleware, a Java-based racing agent, and IBM Granite to analyze driving data and provide feedback during racing.

My Role

As one of the project leads and a core developer, I worked mainly on the Python middleware, system integration, and testing. I also helped coordinate the development of our 7-person Agile team.

What I Worked On

  • Built a Python middleware pipeline to collect real-time TORCS telemetry through UDP.
  • Integrated driving data from an existing Java-based racing agent to provide expert data for comparison with player performance.
  • Designed the system architecture to separate real-time telemetry processing from slower LLM inference.
  • Replaced file-based communication with queue-based data transfer and multiprocessing to reduce input and GUI delays.
  • Integrated IBM Granite through Ollama to generate telemetry-based driver coaching.
  • Developed automated tests using pytest and supported integration across different components.
  • Coordinated development tasks, reviewed pull requests, and supported cross-team integration as a project lead.

Technologies

Python · UDP · Multiprocessing · IBM Granite · pytest · GitHub · Agile
